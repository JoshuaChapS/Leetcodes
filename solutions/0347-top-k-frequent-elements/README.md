# 347. top-k-frequent-elements
https://leetcode.com/problems/top-k-frequent-elements/

- **Patrón:** bucket sort — indexar por frecuencia cuando el rango está acotado
- **Señal:** "los k más/menos frecuentes" y el valor a ordenar está acotado por n
- **Tiempo:** O(n) · **Espacio:** O(n)
- **Intento:** salió con pista (la idea de indexar por frecuencia)
